## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Instance Isolation** | Each instance has separate mods, saves, resource packs, and settings |
| **Legacy Support** | Run any Minecraft version from Alpha to the latest release |
| **Multi-Loader** | Install Fabric, Forge, LiteLoader, and vanilla in separate instances |
| **Lightweight** | Fast, minimal launcher that stays out of your way |
